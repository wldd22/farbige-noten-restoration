# Working

This folder contains intermediate materials created for use during the restoration process. The following is an overview of its folders

```
/png-scans  - PNG scans of original pages, from the source PDFs
              Generated using scripts/pdf_to_pngs.py
/bw-scans   - Black and white versions of png-scans generated using #2
              Generated using scripts/to_bw.py
/ocr-ready  - Black and white scans manually cropped to body text
```
